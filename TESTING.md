## Полный чеклист тестирования

### 1. ✅ Базовая функциональность

**Регистрация и вход:**
- [ ] Откройте http://localhost:8080
- [ ] Нажмите "Регистрация"
- [ ] Заполните форму:
  - Email: test@example.com
  - Пароль: TestPassword123!
- [ ] Нажмите "Зарегистрироваться"
- [ ] Проверьте, что произошел автоматический вход

**Выход и повторный вход:**
- [ ] Нажмите кнопку "Выход" 🚪
- [ ] Нажмите "Вход"
- [ ] Введите те же данные
- [ ] Проверьте успешный вход

### 2. ✅ Управление подписками

**Добавление подписки из популярных:**
- [ ] Нажмите "Добавить подписку"
- [ ] Выберите из популярных (например, Netflix)
- [ ] Проверьте, что поля заполнились автоматически
- [ ] Измените сумму, если нужно
- [ ] Выберите дату следующего платежа
- [ ] Нажмите "Добавить подписку"
- [ ] Проверьте, что подписка появилась в списке

**Добавление пользовательской подписки:**
- [ ] Нажмите "Добавить подписку"
- [ ] Включите "Ручной режим"
- [ ] Заполните вручную:
  - Название: "Моя подписка"
  - Категория: Software
  - Сумма: 999
  - Период: Monthly
- [ ] Нажмите "Добавить"
- [ ] Проверьте появление в списке

**Редактирование подписки:**
- [ ] Нажмите на подписку в списке
- [ ] Измените сумму
- [ ] Нажмите "Сохранить"
- [ ] Проверьте, что изменения сохранились

**Удаление подписки:**
- [ ] Нажмите на подписку
- [ ] Нажмите "Удалить"
- [ ] Подтвердите удаление
- [ ] Проверьте, что подписка исчезла

### 3. ✅ Фильтрация и поиск

**Фильтр по категориям:**
- [ ] Добавьте подписки из разных категорий
- [ ] Нажмите на фильтр категории (например, "Streaming")
- [ ] Проверьте, что показываются только подписки этой категории
- [ ] Нажмите "Все" - вернулись все подписки

**Поиск:**
- [ ] Добавьте несколько подписок
- [ ] Введите название в поиск (например, "Net")
- [ ] Проверьте, что отображается только Netflix
- [ ] Очистите поиск - вернулись все подписки

### 4. ✅ Статистика и графики

**Карточки статистики:**
- [ ] Проверьте, что отображаются:
  - Общая сумма в месяц

**График месячных расходов:**

- [ ] Обновите страницу

- [ ] Наведите на точки графика - показываются суммы

**График по категориям:**

- [ ] Проверьте, что цвета разные для каждой категории

## 📊 Автоматическое тестирование (API)

### Используйте curl для тестирования API:

**1. Регистрация:**
```bash
curl -X POST http://localhost:8080/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{
    "email": "test@example.com",
    "password": "Password123!"
  }'
```

**2. Вход:**
```bash
TOKEN=$(curl -X POST http://localhost:8080/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{
    "email": "test@example.com",
    "password": "Password123!"
  }' | jq -r '.token')

echo "Token: $TOKEN"
```

**3. Получение подписок:**
```bash
curl http://localhost:8080/api/subscriptions \
  -H "Authorization: Bearer $TOKEN"
```

**4. Добавление подписки:**
```bash
curl -X POST http://localhost:8080/api/subscriptions \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Netflix",
    "amount": 649,
    "currency": "RUB",
    "billing_period": "monthly",
    "next_billing_date": "2025-01-01",
    "category": "streaming"
  }'
```

**5. Получение статистики:**
```bash
curl http://localhost:8080/api/subscriptions/stats \
  -H "Authorization: Bearer $TOKEN"
```

## 🆘 Если что-то не работает

**1. Перезапустите контейнеры:**
```bash
docker-compose restart
```

**2. Пересоберите с нуля:**
```bash
docker-compose down -v
docker-compose up --build
```

**3. Проверьте логи:**
```bash
docker-compose logs
```

**4. Проверьте, что порты не заняты:**
```bash
lsof -i :8080
lsof -i :5432
```

**5. Проверьте .env файл:**
```bash
cat .env
```
