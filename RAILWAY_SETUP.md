# Railway Deployment Guide

Это руководство поможет вам задеплоить приложение Subscription Manager на Railway.

## Необходимые шаги

### 1. Создайте новый проект в Railway

1. Зайдите на [railway.app](https://railway.app)
2. Нажмите "New Project"
3. Выберите "Deploy from GitHub repo"
4. Выберите ваш репозиторий

### 2. Добавьте PostgreSQL базу данных

1. В вашем проекте нажмите "+ New"
2. Выберите "Database" → "Add PostgreSQL"
3. Railway автоматически создаст переменную окружения `DATABASE_URL`

### 3. Настройте переменные окружения

В настройках вашего приложения (не базы данных) добавьте следующие переменные:

#### Обязательные переменные:

- `JWT_SECRET` - секретный ключ для JWT токенов (например: `your-super-secret-jwt-key-change-in-production`)
- `APP_ENV` - окружение (установите `production`)

#### Опциональные переменные:

- `TELEGRAM_BOT_TOKEN` - токен вашего Telegram бота (если хотите использовать Telegram уведомления)
- `PORT` - порт сервера (Railway автоматически установит, но можете указать свой)

### 4. Проверьте настройки

Railway автоматически обнаружит Dockerfile и начнет деплой. Приложение будет:

1. ✅ Собрано с использованием Dockerfile
2. ✅ Автоматически запустит миграции базы данных
3. ✅ Подключится к PostgreSQL используя `DATABASE_URL`
4. ✅ Запустится на порту, указанном Railway

### 5. Проверьте деплой

После успешного деплоя:

1. Railway предоставит вам публичный URL
2. Откройте логи приложения и проверьте:
   - `Database is ready!` - база данных доступна
   - `Migrations completed successfully` - миграции выполнены
   - `Successfully connected to database` - приложение подключено к БД
   - `Server starting on 0.0.0.0:XXXX` - сервер запущен

### 6. Настройте домен (опционально)

1. В настройках приложения перейдите в "Settings" → "Domains"
2. Добавьте свой кастомный домен или используйте домен от Railway

## Переменные окружения, которые приложение поддерживает

### Автоматически используемые Railway:

- `DATABASE_URL` - ✅ Автоматически создается Railway для PostgreSQL
- `PORT` - ✅ Автоматически создается Railway

### Вы должны установить вручную:

- `JWT_SECRET` - ⚠️ **ОБЯЗАТЕЛЬНО** для работы аутентификации
- `APP_ENV` - рекомендуется установить в `production`
- `TELEGRAM_BOT_TOKEN` - опционально, для Telegram интеграции

## Troubleshooting

### Ошибка: "Failed to connect to database"

Проверьте:
- PostgreSQL сервис добавлен в проект
- Переменная `DATABASE_URL` присутствует в настройках приложения
- Приложение и база данных находятся в одном проекте Railway

### Ошибка при миграциях

Проверьте логи деплоя на наличие ошибок миграций. Вы можете вручную подключиться к базе через Railway CLI и проверить таблицы.

### Приложение не запускается

1. Проверьте логи деплоя
2. Убедитесь что `JWT_SECRET` установлен
3. Проверьте что build прошел успешно

## Ручной запуск миграций (если нужно)

Если нужно вручную запустить миграции:

```bash
# Установите Railway CLI
npm i -g @railway/cli

# Войдите в Railway
railway login

# Подключитесь к вашему проекту
railway link

# Подключитесь к PostgreSQL
railway connect postgres

# Выполните миграции вручную
\i /path/to/migrations/001_init_schema.sql
```

## Мониторинг

Railway предоставляет:
- Логи в реальном времени
- Метрики использования CPU/RAM
- Историю деплоев
- Автоматический redeploy при push в GitHub

## Поддержка

Если у вас возникли проблемы:
1. Проверьте логи в Railway Dashboard
2. Убедитесь что все переменные окружения установлены
3. Проверьте статус PostgreSQL сервиса
