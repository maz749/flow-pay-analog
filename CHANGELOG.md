# Changelog

Все важные изменения в проекте FlowPay будут документированы в этом файле.

## [1.0.0] - 2024-01-15

### Добавлено
- Система аутентификации с JWT токенами
- REST API для управления подписками
- CRUD операции для подписок
- Поддержка различных периодов оплаты (месяц, год, неделя, кастомный)
- Telegram бот для уведомлений
- Система напоминаний с настраиваемыми интервалами (1, 3, 7, 14 дней)
- Статистика расходов (месячная и годовая)
- Адаптивный веб-интерфейс
- Поддержка категорий подписок
- PostgreSQL база данных
- Docker и Docker Compose конфигурация
- Полная документация и примеры API

### Возможности
- Регистрация и авторизация пользователей
- Добавление, редактирование и удаление подписок
- Автоматический расчет следующей даты списания
- Telegram уведомления о предстоящих платежах
- История уведомлений
- Адаптивный дизайн для мобильных устройств
- Поддержка нескольких валют (RUB, USD, EUR)

### Технический стек
- Backend: Go 1.21
- Database: PostgreSQL 15
- Frontend: HTML5, CSS3, JavaScript (Vanilla)
- Deployment: Docker, Docker Compose
- Libraries:
  - gorilla/mux - Роутинг
  - golang-jwt/jwt - JWT аутентификация
  - jmoiron/sqlx - Database
  - telegram-bot-api - Telegram интеграция
  - robfig/cron - Планировщик задач
